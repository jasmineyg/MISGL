MISGL 代码整理总结

本次整理保留方法主链：稀疏 GAT → 7 维结构增强 MIL → 可选 POS-HEAD。

配置与开关

  • 合并为唯一配置文件 config/train.yml，由严格 dataclass 校验。
  • 明确三种合法模式：baseline（MIL off / POS off）、MIL（on / off）、MIL + POS（on / on）。
  • POS-HEAD 依赖 MIL-HEAD；非法组合立即报错。

核心实现

  • 删除 DiffPool、branch A/B、coarse/stage 等遗留命名，统一为 MILHead、POSHead 与 MISGLModel。
  • 保留 7 维结构特征、结构编码、门控残差融合及注意力形状损失；结构特征只在加载数据时计算一次。
  • 子图改为稀疏边列表批处理，GAT 只处理实际边和自环，训练主路径复杂度为 O(H(E+N))。
  • POS 图仍按 SᵀAS、去自环、对称化、逐行 top-k、行归一化构建。
  • 交叉验证改为内存中的分组分层折叠，不再读写 split JSON，也不包含失败兜底分支。

清理

  • 移除旧训练入口、旧评估/配置工具、coarse GCN 实验、无用测试与 JSON 输出。
  • 本地研究脚本和实验产物已取消 Git 跟踪并加入忽略规则，不会提交到远程。

验证

通过：7/7 单元与合成端到端测试。

验证只使用内存合成数据；未使用 Flickr 数据集。
